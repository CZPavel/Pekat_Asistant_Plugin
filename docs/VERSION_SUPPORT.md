# Version support

This is evidence-aware guidance, not a compatibility certificate. Identify exact PEKAT version, build, project origin and relevant runtime before concluding support. See the packaged `VERSION_ROUTING.md` and `PEKAT_VERSION_CAPABILITY_DELTA.md` for context.

| Version | Evidence boundary |
|---|---|
| 3.18 | General historical context only in this pack; no exact-build implementation or migration equivalence established. Obtain exact documentation and project evidence. |
| 3.19.3 | Historical controlled migration lineage compared with a migrated 4.0.1 fixture. No general migration guarantee. |
| 4.0.1 | Selected generated FLOW/Classifier and embedded Python/ML observations on a tested machine, within their original scope. Installed packages are not necessarily clean-install features. |
| 4.0.3 | Principal source of bounded historical observations for selected workflows and variants. These do not validate arbitrary operations, another patch, a new host or hardware. |

Other or unknown versions require target-specific evidence. Project comparison, package presence, import, functional compute and production acceptance are distinct. No version was live-tested by these documents.
